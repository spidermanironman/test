# 流程图图片处理器

将黑色背景的流程图转换为白色背景，同时将浅色文字变为深色，并提高清晰度。

## 🚀 快速使用

### 方法1：浏览器工具（最简单）

1. 在浏览器中打开 `image_processor.html` 文件
2. 拖拽或点击上传您的图片
3. 调整选项（可选）
4. 点击"处理图片"
5. 下载处理后的结果

### 方法2：Python 命令行

```bash
# 安装依赖
pip install pillow opencv-python numpy

# 快速处理
python quick_process.py 你的图片.png

# 或者使用完整版本
python process_uploaded_image.py 你的图片.png
```

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `image_processor.html` | 浏览器版本，无需安装，拖拽即用 |
| `quick_process.py` | 简洁版Python脚本 |
| `process_uploaded_image.py` | 完整版Python脚本，更多选项 |
| `invert_flowchart.py` | 详细版本，支持多种处理模式 |

## ✨ 功能特性

- **背景转换**: 黑色背景 → 白色背景
- **文字对比**: 浅色文字 → 深色文字
- **颜色保留**: 保留彩色元素（橙色、蓝色、绿色、紫色等）
- **清晰度增强**: 
  - 2倍分辨率放大（LANCZOS插值）
  - 锐化增强
  - USM锐化
  - 对比度优化

## 🔧 自定义选项

在 HTML 工具中可以调整：
- 是否增强锐度
- 是否2倍放大
- 是否增强对比度
- 对比度级别（1.0-1.5）

## 💡 提示

- 处理大图片可能需要几秒钟
- 建议保存为 PNG 格式以保持最佳质量
- 如果颜色效果不理想，可以调整对比度参数
