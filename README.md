# GC耗时分析

本项目说明应用GC（垃圾回收）耗时的含义和重要性。

## 文档

- [GC耗时说明.md](./GC耗时说明.md) - 详细解释GC耗时说明了什么，包括性能指标、内存使用模式、系统健康状态等

## 主要内容

GC耗时说明了：

1. **应用性能指标** - 反映应用在内存管理上的开销
2. **内存使用模式** - 揭示内存分配和回收的模式
3. **系统健康状态** - 判断系统是否存在性能问题
4. **应用暂停时间** - 影响用户体验的关键指标
5. **资源竞争情况** - CPU和内存资源的利用情况

## 快速参考

- **正常GC耗时**：< 100ms
- **需要关注**：100ms - 1s
- **严重问题**：> 1s
