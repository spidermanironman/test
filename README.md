# CPU延迟时间定义

## CPU延迟时间（CPU Latency）是什么？

CPU延迟时间是指CPU执行某个操作或响应某个事件所需的时间。它是衡量CPU性能的重要指标之一。

### 主要类型

1. **指令延迟（Instruction Latency）**
   - CPU执行单条指令所需的时间
   - 通常以时钟周期（clock cycles）为单位
   - 不同指令的延迟时间不同

2. **内存访问延迟（Memory Access Latency）**
   - CPU从内存读取或写入数据所需的时间
   - 包括缓存命中/未命中的情况
   - L1缓存延迟通常为1-3个时钟周期
   - L2缓存延迟通常为10-20个时钟周期
   - 主内存延迟通常为100-300个时钟周期

3. **中断延迟（Interrupt Latency）**
   - 从硬件中断发生到CPU开始处理中断的时间
   - 对实时系统至关重要

4. **上下文切换延迟（Context Switch Latency）**
   - CPU从一个进程/线程切换到另一个所需的时间
   - 包括保存和恢复寄存器状态的时间

### 影响因素

- CPU架构和微架构设计
- 时钟频率
- 缓存层次结构
- 内存子系统性能
- 操作系统调度策略

### 测量单位

- **纳秒（ns）**：最常用的时间单位
- **时钟周期（cycles）**：相对于CPU频率的测量
- **微秒（μs）**：用于较长的延迟测量

### 实际意义

CPU延迟时间直接影响：
- 应用程序的响应速度
- 系统整体性能
- 实时系统的可预测性
- 高并发场景下的吞吐量
