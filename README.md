## 快速参考

### 主线程卡顿的主要原因

| 原因 | 严重程度 | 解决方案 |
|------|---------|---------|
| 长时间 JS 执行 | 🔴 高 | Web Workers / 任务分片 |
| 强制同步布局 | 🔴 高 | 分离读写操作 |
| 大量 DOM 操作 | 🟠 中 | DocumentFragment / 虚拟 DOM |
| 复杂 CSS 计算 | 🟠 中 | 简化选择器 |
| 同步资源加载 | 🔴 高 | async/defer 加载 |

### 保持动画流畅的黄金法则

1. **每帧预算 16.67ms** - 保持 60fps 需要每帧在 16ms 内完成
2. **使用 CSS 动画** - 优先使用 `transform` 和 `opacity`
3. **避免阻塞主线程** - 耗时操作放入 Web Workers
4. **批量操作** - DOM 操作和样式更改应批量进行
