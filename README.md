# Android InputDispatcher 事件时间点分析工具

## 项目说明

本项目用于分析 Android 系统日志中的 InputDispatcher 事件，特别是输入事件分发到应用的时间点以及 ANR (Application Not Responding) 相关的时间线。

## 文件说明

- `analyze_input_timing.py` - Python 分析脚本，解析日志并提取关键时间点
- `分析报告.md` - 详细的中文分析报告，包含时间线分析和问题排查建议

## 使用方法

### 运行分析脚本

```bash
python3 analyze_input_timing.py
```

脚本会分析内置的示例日志，输出详细的时间线分析。

### 分析自定义日志

修改 `analyze_input_timing.py` 中的 `logs` 列表，替换为你的日志内容，然后运行脚本。
